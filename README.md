# Windows XP Experience

A nostalgic browser-based Windows XP-inspired desktop experience featuring an MSN Messenger-style messaging app, a Yahoo-inspired browser, and a Winamp-like music player visualizer.

## About this project

This project recreates the charm of the early 2000s desktop environment with a playful mix of classic web apps and retro UI design. It blends a functional chat interface inspired by MSN Messenger with a web browser shell styled after Yahoo and a music player with an animated visualizer reminiscent of Winamp.

## Features

- MSN Messenger-inspired messaging panel
  - Contact list
  - Conversation windows
  - Status indicators
  - Classic chat layout and interactions

- Yahoo browser-inspired browsing experience
  - Retro homepage styling
  - Search-inspired interface
  - Webpage-like panels and navigation feel
  - Nostalgic internet-era aesthetics

- Winamp-style music player and visualizer
  - Audio controls
  - Animated equalizer / visualizer effects
  - Retro player UI inspired by classic desktop media apps

- Windows XP themed desktop design
  - Familiar colors, gradients, and window chrome
  - Floating application windows
  - Old-school desktop feel

## Run locally

Because this is a static front-end project, you can run it by opening the main page in a browser.

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Explore the desktop, launch the messenger, visit the Yahoo-style browser, and start the music visualizer.

## Files

- `index.html` — main desktop interface
- `msn_messenger.js` — MSN Messenger-inspired chat functionality
- `yahoo_browser.js` — Yahoo-style browser behavior
- `winamp.js` — music player and visualizer logic

## Notes

This project is designed as a nostalgic retro demo and is meant to evoke the feeling of classic desktop software from the early 2000s. It is a playful homage rather than a production-ready application.
